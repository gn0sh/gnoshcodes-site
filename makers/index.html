MakersFor people with a Bambu Lab printer.

Free skills for Bambu Studio.

They set up your print settings and check them before you print. They run in an AI coding agent such as Claude Code.

  • Free
  • MIT license
  • On GitHub

The skills

Two ready. One coming.

A skill is a folder of instructions and scripts that your agent follows. Copy one in, then ask for what you want in plain words.

  • bambu-studio-settings

    Ready
    • Makes user presets and tunes project files (.3mf), for the whole plate or for single objects.
    • Checks a project before you print: filament slots, bed bounds, overlaps, the prime tower and per-object settings.
    • Previews presets as a dry run and writes only new files, never over your originals.

    Cloud sync A new user preset syncs to your Bambu account and your other computers. Settings inside a project file do not sync.

    Needs Python 3.8 or later and Bambu Studio. No extra packages.

    Get it on GitHub →

    Install in two steps

    1. Get the bambu-studio-settings folder from GitHub.
    2. Copy it into ~/.claude/skills/, or upload its zip as a skill.

  • print-object-analyzer

    Ready
    • Reads the real geometry of each part on a plate, or in STL files.
    • Proposes print settings per object, with the measurement behind each one.
    • Keeps your tested settings: a part whose fit already passed keeps the settings it passed at.

    Needs Python 3.8 or later with numpy. For .3mf files it also needs bambu-studio-settings.

    Get it on GitHub →

    Install in two steps

    1. Get the print-object-analyzer folder from GitHub.
    2. Copy it into ~/.claude/skills/, next to bambu-studio-settings, or upload its zip as a skill.

  • Telltile™

    Coming

    Print a tile, take a photo, get settings for that filament.

Each folder has its own README with install steps, safety notes and limits. See the whole project on GitHub.
